# 💳 پلتفرم اعتباری پی‌مان (Payman BNPL)

پی‌مان یک پلتفرم بومی با مدل **«الان بخر، بعداً پرداخت کن» (Buy Now, Pay Later)** است. این سیستم به کاربران اجازه می‌دهد بدون نیاز به ضامن یا ارائه چک و سفته، خریدهای خود را انجام داده و هزینه آن را در ۴ قسط مساوی پرداخت کنند.

*نکته: این پروژه به عنوان یک **MVP (کمینه محصول پذیرفتنی)** طراحی شده است تا با حداقل زمان، ارزش اصلی کسب‌وکار و رابط کاربری (UI) اولیه آن پیاده‌سازی و ارائه شود.*

## ⚙️ راهنمای نصب و اجرا در محیط محلی (Local)

برای اجرای این پروژه روی سیستم خود (محیط لینوکس)، مراحل زیر را دنبال کنید:

1. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/your-username/payman-bnpl.git
   cd payman-bnpl
   ```

2. **نصب وابستگی‌های بک‌اند:**
   ```bash
   composer install
   ```
   ```bash
   cp .env.example .env
   ```
   ```bash
   php artisan key:generate
   ```
   ```bash
   touch database/database.sqlite
   ```
   ```bash
   php artisan migrate --seed
   ```

3. **اجرای سرور توسعه:**
   ```bash
   php artisan serve
   ```
   پروژه روی آدرس `http://127.0.0.1:8000` در دسترس خواهد بود
